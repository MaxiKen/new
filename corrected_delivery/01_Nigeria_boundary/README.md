# Whole-Nigeria boundary
`nigeria_admin0.shp` — single MultiPolygon of the whole country (Natural Earth v5.1.1 Admin 0, EPSG:4326, 907,498 km²). This is the exact frame used to clip/fill the corrected geology layer and to clip rivers. It was missing from the previous inner zip files; it is included here as its own folder. State and LGA boundaries are in `../07_Reference_layers/`.
